  • Help

    Aeronautical Information Service (AIS) of Latvia website provides tools for Data/information submission and Data distribution of aeronautical information concerning the entire territory of the Republic of Latvia and the relevant airspace.

    The user can log in and start using Data distribution tool and Data/information submission tool upon reception of approval by the AIS staff and after the approval, website’s server will send an e-mail with automatically generated code-key table.

    Click on LOG IN

    • Upper field:input user name
    • Middle field: input password
    • Lower field: input access code from the code-key table according to the displayed number
       

    The code-key table is a set of 36 numbers (each number contains 6 digits)

    Click on LOG IN

    In order to open User profile, after logging in, in the main menu click on the user icon next to your name and surname. In order to open Data/information submission tool or Data distribution tool go to section TOOLS on menu.

    ANID tools manual can be found here.
